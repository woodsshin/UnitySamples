# Third Party Notices

This package does not contain third-party code, libraries or assets.

* The network code (SSDP, a small HTTP/1.1 client, SOAP and an XML reader) was written for this package and uses only
  the .NET base class library that ships with Unity.
* The protocols follow the public *UPnP Device Architecture* and *Internet Gateway Device (IGD)* specifications of the
  UPnP Forum / Open Connectivity Foundation.
* The API is modeled on the *SimpleUPNP* plugin for Unreal Engine (<https://github.com/woodsshin/UPNPSample>).
  No source code of that plugin was copied.
* The unit tests use NUnit through the Unity Test Framework, which is installed by Unity and not part of this package.
